Kết nối Gemini API

Key chỉ lưu trong trình duyệt này, không nằm trong mã nguồn.
Nên dùng model Flash hoặc Flash-Lite, thuộc gói miễn phí.

Cách lấy API key

  1. Vào aistudio.google.com/apikey và đăng nhập tài khoản Google.
  2. Bấm Create API key, sao chép chuỗi key vừa tạo.
  3. Dán vào ô API key bên trái, bấm Lưu lại.
  4. Bấm Tải danh sách để kiểm tra key và chọn model.

Gói miễn phí không cần thẻ thanh toán, có giới hạn số lượt gọi mỗi phút và mỗi ngày. Nếu thấy thông báo "Vượt hạn mức miễn phí" thì đợi một lúc hoặc chuyển sang model Flash-Lite.
